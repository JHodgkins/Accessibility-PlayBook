# Further reading

**Audience:** Designers, developers, QA, accessibility specialists and procurement  
**Purpose:** Find the source behind a requirement or implementation decision.

Links reviewed on 20 September 2026. Standards are normative; tutorials and patterns
help with implementation and do not replace testing the finished product.

- [WCAG 2.2 Recommendation](https://www.w3.org/TR/WCAG22/) — success criteria and conformance requirements.
- [EN 301 549 V3.2.1, official ETSI PDF](https://www.etsi.org/deliver/etsi_en/301500_301599/301549/03.02.01_60/en_301549v030201p.pdf) — the explicitly versioned source for this POC's EN mappings.
- [WAI-ARIA 1.2](https://www.w3.org/TR/wai-aria-1.2/) — roles, states and properties.
- [WAI modal dialog pattern](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/) — focus and interaction considerations.
- [WAI tabs pattern](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/) — selection and keyboard models.
- [WAI accordion pattern](https://www.w3.org/WAI/ARIA/apg/patterns/accordion/) — disclosure structure and behaviour.
- [WAI tables tutorial](https://www.w3.org/WAI/tutorials/tables/) — table headers and relationships.
- [HTML dialog specification](https://html.spec.whatwg.org/multipage/interactive-elements.html#the-dialog-element) — browser-defined native behaviour.
- [MDN dialog reference](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/dialog) — examples and browser compatibility.

Start with the [testing baseline](/standards/testing-baseline) to decide how to verify
an implementation. Use the [glossary](/resources/glossary) for terminology.
