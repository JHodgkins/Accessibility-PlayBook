# WCAG 2.2

**Audience:** Product, Design, Development, QA, Accessibility  
**Purpose:** Explain how WCAG supports the playbook without turning the playbook into a success-criterion index.

WCAG 2.2 provides internationally recognised testable success criteria for web
accessibility. This playbook maps relevant guidance to WCAG where useful, but
organises content around product work such as forms, dialogs, keyboard behaviour and
testing.

Always use the authoritative W3C specification when exact normative wording matters.

Use the [WCAG 2.2 Recommendation](https://www.w3.org/TR/WCAG22/) for the standard,
the [organisation baseline](/standards/organisational-requirements) for the example
policy, and the [testing baseline](/standards/testing-baseline) for evaluation.
Level AA includes applicable Level A criteria; a collection of selected checks is
not a whole-scope conformance assessment.
