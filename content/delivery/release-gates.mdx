# Release gates

An example release gate can require:

- planned accessibility testing is complete;
- no unresolved Critical accessibility defects remain;
- High defects have an explicit release decision and remediation plan;
- material exceptions are authorised;
- evidence is attached to the release record;
- known systemic issues have an owner.

Release gates should be proportionate to product risk and organisation policy.
